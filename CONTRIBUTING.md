# Contributing

Open Conduct is a founder-led proposal project maintained by Brent Turner.
Thoughtful corrections, challenges, research, use cases, and implementation
ideas are welcome. Submission does not guarantee review, incorporation, a
personal response, project membership, or governance authority.

## Where to contribute

- Use https://openconduct.org/contribute for substantive proposals, research,
  cultural or labor concerns, protection ideas, and challenges to the standard.
- Use a GitHub issue or pull request for a focused correction when those
  features are available.
- Send security reports privately to security@openconduct.org.
- Send privacy questions privately to privacy@openconduct.org.

Do not place private, confidential, security-sensitive, or personal information
in a public issue or pull request. Do not submit real conduct histories or
information about identifiable consumers or workers.
